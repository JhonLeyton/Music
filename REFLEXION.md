# 📘 Reflexión del Proyecto

## 1. ¿Qué fue lo más difícil del proyecto?

Lo más difícil fue configurar correctamente el entorno de Astro.js y resolver problemas relacionados con npm y la estructura del proyecto. También fue un reto integrar el editor de Strudel y lograr que el sitio tuviera un diseño moderno e interactivo.

---

## 2. ¿Qué aprendiste durante el desarrollo?

Aprendí cómo funciona Astro.js para crear sitios modernos, cómo desplegar proyectos usando Vercel y cómo integrar herramientas externas mediante iframes. También aprendí sobre diseño UI futurista, live coding musical y organización de componentes web.

---

## 3. ¿Qué mejorarías si tuvieras más tiempo?

Si tuviera más tiempo, agregaría un visualizador de audio en tiempo real, efectos visuales más avanzados, almacenamiento de composiciones musicales y generación automática de música usando inteligencia artificial. También mejoraría la interacción del usuario con más animaciones y funcionalidades musicales.
